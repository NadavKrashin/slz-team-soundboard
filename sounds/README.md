# Recordings

Each person has their own folder, named after them and numbered left → right,
top → bottom on the board: `person-01-הודי`, `person-02-יניב`, … `person-12-גוש`.

Drop as many recordings as you like into a person's folder: MP3 (recommended), M4A,
WAV or OGG. Any file name works. Each tap on that person plays a random one of
their clips. Every clip plays once before any repeats, and the same clip never
plays twice in a row.

A person with an empty folder shows a "coming soon" bubble when tapped.
